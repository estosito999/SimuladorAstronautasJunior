# Texturas

El prototipo utiliza materiales y geometrías procedurales de Three.js. No necesita texturas externas.

Esta carpeta puede alojar futuras texturas optimizadas para el terreno o los equipos. Usa dimensiones moderadas, reutiliza materiales y evita archivos grandes para conservar el rendimiento en computadoras escolares. Guarda junto a cada recurso sus créditos y licencia.
